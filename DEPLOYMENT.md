# DREAMSCAPE — Deployment Guide

## Build Output

After running `npm run build`, the `dist/` folder contains:

```
dist/
├── index.html              # Entry point
├── manifest.webmanifest    # PWA manifest
├── registerSW.js           # Service worker registration
├── assets/
│   ├── index-*.js          # Main game bundle (~140 KB gzipped)
│   ├── three-*.js          # Three.js (~112 KB gzipped)
│   ├── tone-*.js           # Tone.js (~57 KB gzipped)
│   └── gsap-*.js           # GSAP (~27 KB gzipped)
└── *.png                   # PWA icons
```

Total: ~200 KB gzipped (excellent for mobile)

## Deployment Targets

### Netlify (Recommended)
1. Drag `dist` folder to Netlify dashboard
2. Or connect Git repo: Build command `npm run build`, Publish directory `dist`
3. Automatic HTTPS, CDN, cache headers

### Vercel
```bash
npx vercel deploy dist --prod
```
Or connect Git repo for automatic deployments.

### GitHub Pages
```bash
# Build
npm run build

# Deploy to gh-pages branch
npx gh-pages -d dist
```
Enable Pages in repo settings → Source: `gh-pages` branch.

### Cloudflare Pages
1. Connect repository
2. Build command: `npm run build`
3. Build output directory: `dist`
4. Automatic deployments on push

### Firebase Hosting
```bash
npm run build
firebase deploy --only hosting
```

### Docker (for custom hosting)
```dockerfile
FROM nginx:alpine
COPY dist/ /usr/share/nginx/html/
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

`nginx.conf`:
```nginx
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    # SPA fallback
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Cache static assets
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # Service worker
    location /registerSW.js {
        expires 0;
        add_header Cache-Control "no-cache";
    }

    # Gzip
    gzip on;
    gzip_types text/css application/javascript;
}
```

### Apache (.htaccess)
```apache
# SPA fallback
RewriteEngine On
RewriteBase /
RewriteRule ^index\.html$ - [L]
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule . /index.html [L]

# Cache assets
<FilesMatch "\.(js|css|png|svg|woff2)$">
    Header set Cache-Control "max-age=31536000, immutable"
</FilesMatch>

# Compress
<IfModule mod_deflate.c>
    AddOutputFilterByType DEFLATE text/html text/css application/javascript
</IfModule>
```

## PWA Configuration

The game includes:
- Web App Manifest (`manifest.webmanifest`)
- Service Worker (auto-generated by Vite PWA plugin)
- Icons: 192×192, 512×512, 180×180 (Apple touch)
- Offline support via Workbox

## Performance Notes

- **Initial load**: ~200 KB gzipped
- **Target**: 60 FPS on 5-year-old phones
- **Quality presets**: Auto-detects device capability
- **Mobile**: Reduced symbol density, no shadows, no bloom
- **Reduced motion**: Respects `prefers-reduced-motion`

## Browser Support

- Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- WebGL2 required (fallback to WebGL1 with reduced features)
- Web Audio API required (silent fallback if unavailable)

## Troubleshooting

### White Screen on Load
- Check browser console for errors
- Verify WebGL support: `webglreport.com`
- Try `?quality=low` query parameter

### Audio Not Playing
- Browser requires user gesture first
- Click anywhere to unlock audio context
- Check `Autoplay` policy in browser settings

### Save Not Persisting
- Check localStorage quota (5 MB typical)
- Private/incognito mode may block storage
- Try clearing site data and reloading

### Mobile Performance Issues
- Reduce quality in settings
- Close other tabs
- Ensure hardware acceleration enabled

## CI/CD Example (GitHub Actions)

```yaml
name: Deploy
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - run: npm run build
      - uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist
```
